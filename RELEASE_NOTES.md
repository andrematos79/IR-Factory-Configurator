# v0.8.0-alpha.1 — Public Technical Showcase

First public documentation release of IR Factory Configurator. Based on the validated engineering baseline v0.8.0 ALPHA 1 HOTFIX 2.1.

## Highlights
- Recipe-driven IR test configuration and synchronization
- Multi-client IR libraries, multi-protocol and RAW infrared
- ESP32 communication over USB/Serial and Wi-Fi
- IR Learning and device recovery workflows
- Engineering documentation and product screenshots
